## Body

```
Pockymod is a free, open-source mod manager for Cyberpunk 2077 on Windows. You browse Nexus mods inside it and press Install. If the mod needs redscript, RED4ext or ArchiveXL, those come too.

Some of what it does:
- a filter for mods updated since your game patch
- Health, which tells you what a patch broke (an old Cyber Engine Tweaks, say) and fixes it with one key
- checking a collection before you install it: what you're missing, how many clicks it takes on a free account, which mods were removed

It picks up the mods you already have, including Vortex's, and Ctrl+Z undoes any change. It's an alpha, so I'd like to hear what breaks.

Nexus: <Nexus page link>
GitHub: https://github.com/imanimal/Pockymod
```
