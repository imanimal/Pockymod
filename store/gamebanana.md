## Description

```
Pockymod installs mods from Nexus Mods, not from GameBanana. You'll need a Nexus account (a free one works).

It's a mod manager for Cyberpunk 2077 on Windows. You browse Nexus mods inside it and press Install, and whatever the mod needs comes along. For Mod Settings that's redscript, RED4ext and ArchiveXL.

What it does

- Installs a mod with its requirements. Premium accounts download straight away. On a free account the app shows each mod's Nexus page, you press Mod Manager Download, and it moves on to the next one.
- Has filters Nexus doesn't, like "updated since your game patch".
- Health checks your frameworks against the game version. After a patch it says what will break, like an old Cyber Engine Tweaks or a missing requirement, and fixes it with one key.
- Before you install a Nexus collection, it shows how many mods you're missing, how many clicks it takes on a free account and which game version it was made for.
- Picks up the mods you already have, including ones Vortex installed. Files you put in by hand are set aside instead of deleted, and Ctrl+Z undoes any change.
- Works with a mouse, the keyboard or a controller.

Installing

Unzip the download and run the setup exe inside. It installs for your Windows user, so it doesn't need admin rights. The installer isn't signed yet, so Windows may say it protected your PC. Click More info, then Run anyway.

On first start, paste your Nexus API key (on nexusmods.com: your avatar, Site preferences, API keys). You can browse without one.

Pockymod updates itself from GitHub. You can turn that off in Settings, Background.

It's an alpha, so expect rough edges. Bug reports are welcome here or on GitHub.

Source code (MIT license): https://github.com/imanimal/Pockymod
```
