## Release notes

The release workflow fills in a changelog link. Write the top part by hand. For the next release:

```
Run Pockymod_1.0.0-alpha.3_x64-setup.exe below to install. If you already have Pockymod, it updates itself.

For Nexus Mods and GameBanana there's also Pockymod-1.0.0-alpha.3-setup.zip, the same installer in a zip.

What changed
- Pressing Mod Manager Download on Pockymod's own Nexus page no longer tries to install the app as a mod. It says what it is and skips it.
- Health lists the areas with problems first.
- Trying a theme no longer pops up a Keep or revert toast. There's a go-back key instead, and a notice no theme can hide.
- In the Nexus pane, the Slow download button stays in the same place on every download page.
```
